# Video SEO Strategy

**Status:** ACCEPTED STRATEGY FRAMEWORK / INVENTORY & TARGETED EVIDENCE PENDING  
**Authority:** DEC-038, DEC-094 through DEC-098, DEC-040 through DEC-048, DEC-129  
**Updated:** 2026-09-26

## Objective

Give every public Mariwork video an explicit host-page relationship, discoverability state, truthful metadata and lifecycle disposition.

## Accepted rules

### Host page / eligibility
- Video structured data is eligibility-driven, not automatic.
- An important/indexable video needs a genuine visible/playable host-page relationship.
- The video must be contextually relevant and sufficiently prominent for the page role.
- Player/embed and required resources must be fetchable where Search discovery is intended.
- Do not manufacture VideoObject markup for hidden, incidental or non-watchable media.

### Academy role
- Current Academy/Guide content is video-first practical/demo/instructional content.
- Host WebPage and eligible primary VideoObject must remain semantically coherent.
- Future genuine Course/Lesson schema relationships are separate from current Guide architecture and must not be fabricated.

### Titles / descriptions
- Truthful, descriptive and subject-specific.
- Avoid generic serial names, stuffing and fabricated details.
- Visible/contextual naming and eligible structured-data metadata must agree semantically.

### Thumbnails
- Factual, clear and representative of the actual video.
- Do not use misleading thumbnails or one generic image across unrelated videos.
- Prefer uniqueness when it materially improves identification; do not create arbitrary differences for SEO.

### Transcript / summary / key text
- Full transcript is not mandatory for every video.
- Add transcript, summary, steps or key text only when materially useful for understanding, accessibility, context or Search.
- Supporting text must accurately reflect the video.
- No filler text to increase page length.

### Duplicate / orphan / weak-context videos
- A media file does not receive independent SEO treatment merely because it exists.
- Establish the primary useful host/version first.
- Consolidate, remove, de-emphasize or relink redundant/weak instances as appropriate.
- Do not create thin standalone SEO pages without a genuine user/Search role.

### Cross-family links
- Video/Academy links to Product/Category and reciprocal links follow DEC-040 through DEC-048.
- No forced commercial or educational link quotas.

## Required inventory fields

For every discovered public video record:
- stable identifier where available;
- host page/entity and family;
- topic/purpose;
- player/embed source;
- crawl/fetch evidence;
- title/description;
- thumbnail;
- surrounding/supporting text;
- transcript/summary availability where relevant;
- structured-data state;
- internal links;
- final disposition;
- QA state.

## Evidence still required before implementation

- representative host-page/player behavior;
- initial HTML/rendered DOM and fetchability where relevant;
- factual thumbnail/source metadata;
- current video inventory and duplicate/orphan mapping.

These are implementation/evidence gates, not unresolved strategy decisions.

## AI / generative-answer relationship

Video titles, surrounding text, transcripts/summaries where useful, factual thumbnails and fetchability support DEC-129. No AI-only fabricated metadata or thin transcript pages are allowed.

## Completion

The program is complete only when discovered public videos are inventoried, assigned a target state, implemented/kept as approved, and pass Codex QA + ChatGPT Final QA.

No Production write is authorized by this strategy file alone.
