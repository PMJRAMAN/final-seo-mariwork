# External PR / Advertorial Strategy

**Status:** DEFERRED — DEC-071 / DEC-101
**Execution timing:** After Query Map, Content Architecture, Internal Link Architecture and priority landing pages are sufficiently stable.

This program must not enter execution while DEC-071/101 remain deferred. The file is retained as future planning structure, not current authorization.
**Scope:** Paid external articles, advertorials, sponsored editorial placements and broader digital PR opportunities.

## Purpose

Use final SEO evidence to decide where external visibility should be directed.

This is not a generic backlink-buying program. The strategy must connect:

External publisher → useful article/topic → correct Mariwork landing page → deliberate internal-link path → measurable user/business/search outcomes.

## Required Inputs

- approved Query / Intent Map;
- Content Architecture;
- Internal Link Architecture;
- GSC opportunity data;
- page/family dossiers;
- legacy URL and canonical decisions;
- final product/category/article/Academy roles;
- approved target pages and content gaps;
- measurement baselines.

## Campaign Planning Fields

Each proposed placement should record:

| Field | Requirement |
|---|---|
| Topic / query cluster | Evidence-backed |
| Audience | Explicit |
| Publisher type | General / art / culture / lifestyle / specialist |
| Article angle | Unique and useful |
| Primary landing page | Durable approved target |
| Supporting internal path | Defined before publication |
| CTA | Appropriate to audience/intent |
| Link/anchor policy | Natural and compliant |
| Paid-link attribute expectation | Record sponsored/nofollow/dofollow observation |
| KPI | Defined before launch |
| Publication date | Recorded |
| Live article URL | Recorded |
| Outcome review | Required |

## Publisher Evaluation

Do not choose publishers by DA/DR alone.

Evaluate:
- topical relevance;
- real audience fit;
- editorial quality;
- likely visibility/readership;
- referral traffic potential;
- brand fit;
- permanence/indexability of the article;
- publication quality and placement context;
- whether the article can stand as useful content independently of its link.

## Landing-Page Rule

Do not default all placements to the homepage or random product URLs.

Possible targets include:
- durable Category / Shop hubs;
- authoritative Articles;
- Academy guides;
- selected Products when commercial intent genuinely matches;
- brand/trust pages for brand-led campaigns.

The target must be chosen from the approved site architecture.

## Internal Distribution Rule

Before publication, define how value and users can continue through Mariwork:

External article
→ primary landing page
→ relevant Category / Product / Academy / Article destinations

This downstream path must be useful to users, not a forced link graph.

## Measurement

Possible KPIs:
- referral sessions and engaged visits;
- assisted conversions where reliable data exists;
- branded-search growth;
- GSC impressions/clicks/CTR/position changes for the target page, interpreted cautiously;
- downstream navigation from the landing page;
- publisher/article-level performance;
- qualitative brand visibility.

No single ranking change should be attributed to one paid article without sufficient evidence.

## Rollout

1. Build campaign matrix.
2. Select a small pilot set across different publisher types.
3. Publish.
4. Measure against baseline.
5. Compare publisher/topic/landing-page combinations.
6. Refine rules.
7. Scale only the combinations that show strategic value.

## Governance

Final publisher selection, budget allocation, article angle, landing page and campaign objective require human approval.

Any SEO interpretation must remain consistent with current official Google guidance at the time of execution.
