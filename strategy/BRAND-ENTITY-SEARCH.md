# Brand / Entity Search Strategy

**Status:** CORE / PLANNED

## Objective

Create a consistent, evidence-backed representation of Mariwork across branded search, site content, structured data and external references.

## Scope

- branded queries and branded landing pages;
- Homepage;
- About / founder / history / contact / trust pages;
- Organization / WebSite / other appropriate entity schema;
- canonical brand name and factual attributes;
- consistent brand naming across titles/content;
- verifiable off-site references;
- interaction with external PR / advertorial campaigns.

## Required Outputs

1. brand/entity baseline;
2. branded-query map;
3. canonical brand facts registry;
4. entity-supporting content gap analysis;
5. schema/ownership target state;
6. off-site reference opportunities based on verifiable facts;
7. implementation plan;
8. branded-search monitoring plan.

## Safety / Accuracy Rule

Never invent awards, credentials, founders, partnerships, reviews, locations, dates or other brand/entity facts for SEO. Unsupported claims remain UNKNOWN_NEEDS_VERIFICATION.
