# SEO Strategy Layer

This directory stores cross-page target-state strategy derived from audited evidence. It does not replace page dossiers, raw GSC data or implementation change dossiers.

## Canonical strategy files

- `DECISION-BACKLOG.md` — canonical owner + ChatGPT target-state decision queue/status.
- `ACCEPTED-DECISIONS.md` — compact accepted-decision register.
- `SEMANTIC-POSITIONING.md` — foundational Mariwork semantic positioning and Product value pillars (DEC-121).
- `CONTENT-ARCHITECTURE.md` — accepted page-family roles and content architecture.
- `QUERY-MAP.md` — research workspace for query/intent clusters; Page→Query ownership still requires joined/direct evidence.
- `INTERNAL-LINK-ARCHITECTURE.md` — accepted internal-link policy.
- `INTERNAL-LINK-REQUIREMENT-MATRIX.md` — canonical accepted link-class/family matrix; exact destinations remain scoped implementation/research inputs.
- `BRAND-ENTITY-SEARCH.md` — canonical verified Mariwork brand/entity facts and boundaries.
- `VISUAL-IMAGE-SEO.md` — accepted image/visual strategy with targeted evidence gates.
- `VIDEO-SEO.md` — accepted video strategy with inventory/evidence gates.
- `AI-ASSISTANT-DISCOVERABILITY.md` — accepted AI-answer discoverability/citation framework (DEC-129).
- `EXTERNAL-PR-STRATEGY.md` — future external PR program; execution remains deferred under DEC-071/101.

## Governance

Strategy findings do not become Production tasks directly.

Flow:
1. evidence/audit;
2. accepted target-state decision;
3. Strategy Lock for a coherent scope;
4. Execution Backlog reconciliation;
5. READY_FOR_TASK;
6. Codex implementation task;
7. Codex QA;
8. ChatGPT Final QA;
9. monitoring.

See `docs/DECISION-TO-EXECUTION-GOVERNANCE.md`.

Files explicitly marked HISTORICAL, DRAFT or SUPERSEDED are traceability artifacts and must not override the canonical files above.
