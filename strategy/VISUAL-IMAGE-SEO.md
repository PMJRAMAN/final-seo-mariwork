# Visual / Image / Multimodal SEO Strategy

**Status:** CORE / PLANNED
**Authority:** Evidence first; target rules require Second Review + approval before implementation.

## Objective

Make important Mariwork visual assets understandable, useful, accessible and discoverable across Product, Category, Article, Academy, Homepage and trust content.

## Scope

- primary product images;
- product galleries;
- instructional images;
- article/Academy illustrations and step images;
- brand/trust imagery where search-relevant;
- image context and internal relationships;
- multimodal / visual-search opportunities.

## Required Decisions

For each family define:
- which images are index/discovery targets versus decorative;
- ALT rules by image role;
- filename policy for new assets;
- primary/representative image rules;
- duplicate/reused-image handling;
- surrounding-text/caption requirements where useful;
- technical delivery requirements;
- image-to-page/query intent alignment.

## Deliverables

1. image inventory;
2. family-level image policy;
3. priority-image issue list;
4. implementation-ready target states;
5. QA/regression coverage;
6. monitoring plan where image-search data is available.

Do not generate keyword-stuffed ALT text or invent visual facts not present in the image.
