# Sitewide Audits

قبل از page batchهای گسترده، baselineهای فنی سراسری اینجا ثبت می‌شوند.

اولین audit باید از:
`templates/SITEWIDE-TECHNICAL-AUDIT.md`

استفاده کند و حداقل `docs/SITEWIDE-TECHNICAL-AUDIT-SPEC.md` را پوشش دهد.

Auditها historical snapshots هستند و overwrite نمی‌شوند؛ audit جدید فایل جدید می‌سازد.
