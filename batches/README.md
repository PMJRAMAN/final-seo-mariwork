# Audit Batches

Batchها واحد مدیریت کار هستند، نه جایگزین dossier.

هر batch:
- انتخاب صفحات را توضیح می‌دهد؛
- audit Codex را هماهنگ می‌کند؛
- Second Review را دنبال می‌کند؛
- cross-page findings را جمع می‌کند.

اطلاعات نهایی هر page باید در dossier خودش باقی بماند.

Batchهای اولیه به‌طور پیش‌فرض ۵ صفحه‌ای هستند.
