# Tasks

Executable Codex task specifications. Task IDs must map to MASTER-TODO.md.


## Implementation gate

`EXECUTION-BACKLOG.md` is the canonical implementation queue.

A Production Codex task must:
- map to MASTER-TODO;
- cite accepted Decision IDs from `strategy/DECISION-BACKLOG.md`;
- cite an Execution ID in `READY_FOR_TASK`;
- satisfy the governance and change-control gates.

No audit finding or recommendation is directly executable.
