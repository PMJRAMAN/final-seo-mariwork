# Measurement Specification v1.0

## 1. Change Annotation

هر implementation:
- implementation date/time
- exact scope
- affected URLs/entities
- systemic change reference
- price/stock/campaign notes if relevant

## 2. Baseline

قبل از تغییر تا حد امکان:
- clicks
- impressions
- CTR
- position
- Page+Query mix
- device
- search appearance
- business conversion metric if reliable

date range ثبت شود.

## 3. Comparison Windows

پیش‌فرض:
- 28 days
- 56 days

اما seasonality/حجم داده می‌تواند window را تغییر دهد.

بازه قبل/بعد تا حد امکان هم‌طول و comparable باشد.

## 4. Confounders

ثبت:
- stock/price change
- migration
- sitewide release
- campaign
- seasonality
- SERP change
- algorithm update known/likely
- query mix shift

## 5. Interpretation

مجاز:
- observed increase/decrease
- correlation with change period
- hypothesis

ممنوع بدون evidence:
- «این تغییر باعث X٪ رشد شد»

## 6. High-Impression / Low-CTR

قبل از title/meta conclusion:
- query mix
- intent mismatch
- broad/ambiguous queries
- SERP features
- average position distribution

بررسی شود.

## 7. Monitoring Result

هر dossier:
- 28d
- 56d
- later notes
- KEEP / ITERATE / ROLLBACK-CANDIDATE / INCONCLUSIVE

می‌تواند داشته باشد.
